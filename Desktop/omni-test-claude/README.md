# Madhuri Goud — ML & Generative AI Portfolio

A responsive, single-page portfolio highlighting production machine learning, Generative AI, RAG, and MLOps experience.

## Run locally

Open `index.html` in a browser, or start a simple static server:

```powershell
python -m http.server 4173
```

Then visit http://localhost:4173.

## Deployment

This site is published through GitHub Pages from the repository's `master` branch at `/Desktop/omni-test-claude/`.
