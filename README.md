# Madhuri Goud — ML & Generative AI Portfolio

A responsive, single-page portfolio highlighting production machine learning, Generative AI, RAG, and MLOps experience.

## Run locally

Open `index.html` in a browser, or start a simple static server:

```powershell
python -m http.server 4173
```

Then visit http://localhost:4173.

## Deployment

This site deploys automatically to GitHub Pages whenever changes are pushed to the `main` branch. After the GitHub Actions workflow finishes, visit https://madhuri3117.github.io/madhu/.
